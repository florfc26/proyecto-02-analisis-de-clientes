Proyecto 02 – Análisis de clientes y compras

 Descripción del proyecto

Este proyecto consiste en analizar los datos de compras de una base de clientes utilizando **Microsoft Excel y Power BI**.

El objetivo es identificar patrones de facturación, conocer el comportamiento de los clientes y comparar las compras según el producto y la provincia.

## Herramientas utilizadas

- Microsoft Excel
- Power BI Desktop
- Power Query
- DAX

 Datos utilizados

Se trabajó con una base de datos ficticia de 10 compras correspondientes a octubre de 2026.

La base contiene las siguientes columnas:

- ID_Cliente
- Cliente
- Provincia
- Fecha_Compra
- Producto
- Importe

 Indicadores principales

El dashboard presenta los siguientes indicadores:

| Indicador | Resultado |
|---|---:|
| Clientes únicos | 6 |
| Cantidad de compras | 10 |
| Facturación total | $5.850.000 |

 Análisis realizados

Se desarrollaron visualizaciones para analizar:

- Facturación por cliente.
- Facturación por provincia.
- Facturación por producto.
- Facturación por cliente y producto.
- Facturación por provincia y producto.

También se incorporó una tabla con el detalle de las compras.

Principales resultados

- Notebook fue el producto con mayor facturación, con $4.600.000.
- Santa Fe fue la provincia con mayor facturación total, con $2.300.000.
- Juan Torres fue el cliente con mayor facturación, con $1.550.000.
- Juan Torres también fue el cliente con mayor facturación en Notebook, con $1.350.000.

Conclusiones

El análisis permitió identificar los productos, clientes y provincias que generaron mayor facturación.

A partir de estos resultados, se pueden proponer estrategias comerciales como campañas publicitarias segmentadas por provincia, promociones y opciones de financiación para los productos con mayor facturación.
